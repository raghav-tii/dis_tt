# T2: bond linear algebra (`src/dis_tt/linalg.py`)

## Plan
1. `select_rank`: clip eigenvalues at 0; tails[r] = suffix sums (or `trace - prefix sum` when
   `trace` is given, clipped at 0); r = smallest r >= 1 with tails[r] <= delta2, then capped by
   rmax and len; `rfixed` overrides; delta2 = rfixed = None -> drop eigs < 1e-14 * eigs[0].
2. `top_eigh_gram`: "gram" = eigh(M M^T); "svd" = thin SVD (full U when c < m so the spectrum
   is complete with zero padding); "auto"; "randomized" = HMT range finder + power iterations,
   always `complete=False`.
3. Extra tests in `tests/test_linalg_extra.py`: all-zero input, k > m, randomized tail via trace.

## Design choices
- Rank-rule comparison is literal `tail <= delta2` (no slack). Tails without `trace` are suffix
  sums of the clipped eigenvalues, so `tail_r` for trailing exact zeros is exactly 0.
- With `trace`, tails are `trace - prefix_sum`, clipped at 0; for r = len(eigs) the tail is the
  mass outside the computed top block, so the delta2 rule may never be met -> r = len(eigs)
  (then rmax), which is the most the incomplete spectrum can certify.
- delta2 = rfixed = None still honours `rmax` (cap), as "then capped by rmax" applies to every
  branch except rfixed. All-zero spectrum -> r = 1, tail = 0.
- Empty `eigs_desc` raises ValueError (r >= 1 cannot be satisfied).
- `top_eigh_gram`: `k` is clipped to [0, m] (k > m returns all m pairs). `complete` is True only
  for exact backends that return all m eigenvalues; `k < m` on an exact backend -> False
  (matches `DISTTResult.spectra_complete` semantics: "possibly truncated by the backend").
- "svd" with c < m uses `full_matrices=True` only when k > c, padding the spectrum with exact
  zeros so the eigenvectors form a complete orthonormal basis (needed for full-rank bonds).
- Eigenvalues are clipped at 0 for all backends.
- "randomized": default `rng = default_rng(0)` (deterministic); sketch width
  `min(k + oversample, m, c)`; power iterations re-orthonormalise via QR on both sides;
  always `complete=False`, even when the sketch spans all of range(M).
