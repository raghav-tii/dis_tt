## Source check (paper TeX `numerical_results.tex`, `mathematical_setup.tex`)
- Architecture eq. (neural_network): d_L affine layers, constant width d_W; `depth` = d_L.
- Table 2: semilinear depth 6, Burgers 4, elasticity 4; width 2r; softplus; LR 1e-3 / 2.5e-4 / 1e-3.
- Training: Adam, batch 25, 3000 epochs, "piecewise constant learning rate schedule that is successively
  halved five times starting at the 2,250th epoch". The halving spacing is NOT stated; this
  implementation spaces them evenly over the remaining epochs (2250, 2400, 2550, 2700, 2850).
- In the paper r_X = r_Y = r; here width = width_factor * max(r_X, r_Y) (interpretation).
- Initialisation (not stated in the paper): W ~ N(0, 1/fan_in), b = 0, float64 (jax x64).

## Findings
- With N = 20 < batch 25 each epoch is ONE Adam step, so the exact Table 2 budget is 3000 steps.
  Measured final training loss (toy, r_Y = 4, r_X = 3, per-sample normalisation, seed 0):
  width 8 (2r), 3000 epochs: 0.2153; 10000: 0.0959; 20000: 0.0695; 60000: 0.0210.
  width 32, 30000: 2.32e-3; width 32, 100000: 7.52e-5; width 64 (16r), 30000: 6.83e-4;
  width 64, 60000: 4.51e-7 (seed 0), 2.83e-7 (seed 1).
  So the paper configuration cannot overfit 20 samples to 1e-3 within its budget here (capacity/steps,
  ~356 parameters vs 320 fitted values). The overfit test therefore uses width 16r and 60000 epochs,
  everything else per Table 2. This is a DEVIATION for the test only; defaults remain the paper's.
