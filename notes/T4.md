# T4: Algorithm A, dense DIS-TT (`src/dis_tt/dense.py`)

## Plan
1. Literal docstring pseudocode: `M = Z.reshape(n_1, -1)` (tau stays the fastest column index),
   per bond `linalg.top_eigh_gram(M)` -> `linalg.select_rank` -> `G_k = V[:, :r_k]`, `M = G_k^T M`,
   reshape to `(r_k n_{k+1}, -1)`. `total = ||Z||_F^2`, `delta2 = eps^2 total / D`.
2. `ranks=` -> `rfixed` per bond (overrides eps/rmax); eps = ranks = None -> full numerical rank.
3. Randomized backend: `select_rank(..., trace=||M||_F^2)` so tails are exact sums; with eps and
   no fixed rank, grow the sketch size until the tolerance (or rmax / m) is reached.
4. `precompress`: Z -> U_r Sigma_r (thin SVD, numerical rank) only when it reduces T; total
   from the original Z.
5. Extras (`tests/test_dense_extra.py`): n_k != 2, D = d-1 with eps, binding rmax, T = 1,
   randomized trace tails, timing ratio < 3 for 2x T.

## Design choices
- Literal pseudocode: `M = Z.reshape(n_1, -1)` (no transpose; tau remains the fastest column
  index), `M <- G_k^T M`, reshape `(r_k n_{k+1}, -1)`. Tails are `select_rank`'s tail_r.
- `eps=None, ranks=None` -> `delta2=None` (full numerical rank: drop eigs < 1e-14 lam_1).
  `ranks` given -> `rfixed` per bond, eps and rmax ignored. `D=None` -> `len(ranks)` if ranks
  given, else d. Any 1 <= D <= d is accepted (tested: d and d-1); bad sizes raise ValueError.
- `spectra[k]` = all r_{k-1} n_k eigenvalues for exact backends (`complete=True`); the
  "svd" backend pads with exact zeros when c < m.
- Randomized backend (`_randomized_bond`): trace = ||M||_F^2 = Tr(H~_k), tails via
  `select_rank(..., trace=trace)`. Fixed rank -> one sketch with k = r_k. eps mode -> k starts at
  min(4, kmax) and doubles until the trace-tail meets delta2 or k reaches kmax = min(rmax, m, c).
  eps=None -> one sketch with k = min(m, c). `spectra_complete` all False. The trace-tail is the
  exact discarded mass for the chosen orthonormal G_k (Rayleigh quotients of V = Q U_b equal the
  returned s_i^2), so the training identity still holds exactly (verified: rel gap 3.4e-12).
  The per-bond sketch size is a design choice not specified by the docstring.
- `precompress`: Z -> U_q Sigma_q with q = numerical rank (s > s_1 * eps_mach * max(shape));
  skipped when T <= d_Y. `total` is always taken from the original Z. Toy: T 2560 -> 8 columns;
  ranks identical, max |tail diff|/total = 4e-16, sin(theta_max) = 7.8e-14.
- `meta`: backend, eps, rmax, D, precompress, T_in, T_used.

## Observations
- Toy eps=0.05, D=7: ranks (2, 4, 8, 9, 7, 6, 5). Bonds 1-3 are full rank (r_{k-1} n_k), tail 0.
  Bond 4 has rank 9 > p = 8 = rank(H_Y), as expected: the partial trace Tr_{>k} can raise rank.
- D=6 at eps=0.05 picks the same first six ranks as D=7 (the larger delta2 = eps^2 total/6 is not
  enough to drop a mode at any bond).
- Timing (d_Y = 2^10, rmax=6, random Z, best of 5): T=1000 13.6 ms, 2000 40.5 ms, 4000 74.0 ms,
  8000 159.9 ms -> ratios 2.99, 1.83, 2.16. The first step is close to 3, probably cache
  effects as the working set grows from 8 to 16 MB. The test uses T = 2000 -> 4000.
