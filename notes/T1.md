# T1: TT toolkit (`src/dis_tt/tt.py`)

## Plan
1. `from_dense`: left-to-right TT-SVD on C-order unfoldings, per-bond threshold
   `eps*||y||/sqrt(d-1)` on the discarded singular-value norm; eps=0 drops s < 1e-14*s_1.
2. `to_dense`/`block_to_dense`: left-to-right contraction `einsum("Ia,air->Iir")`, matching
   `conftest.ref_left_frame`; `subspace_matrix` = `kron(U, I_rest)`.
3. `right_orthogonalize` (QR of transposed right unfoldings, right-to-left), `tt_round`
   (right-orth then truncated SVD left-to-right), `project_block` (environment contraction),
   `block_apply`, `tt_add` (block-diagonal cores).
4. Extra tests in `tests/test_tt_extra.py`: n_k != 2, d = 1, rank caps.

## Design choices
- Shared helper `_truncation_rank(s, delta, rmax)`: smallest r >= 1 with ||s[r:]|| <= delta
  (delta = eps*||y||/sqrt(d-1)); delta = 0 keeps s > 1e-14*s_1; then rmax cap; always r >= 1.
  Used by both `from_dense` and `tt_round`, so both satisfy ||err|| <= eps*||y||.
- d = 1: no bonds, so eps is ignored (exact) and `tt_add` sums the single cores directly.
- `right_orthogonalize` uses reduced QR of the transposed right unfolding; a bond rank larger
  than n_k r_k is reduced to n_k r_k (exact, the represented tensor is unchanged).
- `block_apply` assumes D = d (block TT); `coeffs` is contracted into the last core's column index.
- `project_block` contracts environments E_k(alpha, beta) with `einsum(optimize=True)`; no densification.
- `from_dense` raises ValueError when len(y) != prod(mode_sizes) (extra, not required).

## Deviations
None. No surprises; the C-order / `ref_left_frame` convention held on the first attempt.
