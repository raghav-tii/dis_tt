# T3: snapshot estimators (`src/dis_tt/snapshots.py`)

## Plan
1. One `model.solve` per column of xs; per x one batched `jvp`/`vjp` call on a (dim, k) block.
2. Output DIS directions: "random" fresh `prior.sample(rng, S)` per x, scale 1/sqrt(N S);
   "kl" `phi_j sqrt(mu_j)`, scale 1/sqrt(N); "exact" `L e_j` (= `apply_sqrt(I_white)`), 1/sqrt(N).
3. Output PCA: (y_s - y_bar)/sqrt(N) with the sample mean. Input DIS: `apply_sqrt_T(vjp(eta))`
   (L^T), eta Gaussian (1/sqrt(N S)) or columns of U_out (1/sqrt(N)).
4. Mixed: sqrt(alpha/||Z_pca||^2) Z_pca | sqrt((1-alpha)/||Z_dis||^2) Z_dis.
5. Snapshot columns grouped per sample (x_1's directions first), matching `conftest.ref_output_dis_exact`.

## Design choices
- Extra keyword `batch: bool = True` on `output_dis_snapshots` / `input_dis_snapshots`
  (allowed: extra kwarg with default). True -> one `jvp`/`vjp` call per x on the whole block;
  False -> column-by-column for models without block support. Results agree to 1e-14 (tested).
- `rng=None` -> `np.random.default_rng(0)` (deterministic, same convention as T2's randomized backend).
- "random": a fresh block of S prior draws per x (`prior.sample`), i.e. N*S independent directions.
- "exact": directions `prior.apply_sqrt(I_{white_dim})`, so `n_dirs = white_dim` (works for wide L).
- "kl": `n_dirs = K` columns per x, `phi_j sqrt(mu_j)`; Z Z^T = (1/N) sum DF C_K DF^T <= H_Y.
- Column order: grouped per sample (all directions of x_1, then x_2, ...) as in
  `conftest.ref_output_dis_exact`. This is the snapshot index tau (last tensor mode).
- Gaussian eta for the input side: d_Y read from `model.output(state)` (no extra solve).
- PCA SnapshotSet: `n_dirs = 1`, `direction_kind = ""`.
- Mixed: a block with zero Frobenius norm contributes zeros (avoids 0/0); alpha outside [0, 1]
  and row-size mismatch raise ValueError. meta records `alpha`, `n_pca_cols`, `n_dis_cols`.
- Every SnapshotSet records `meta["scale"]` (the column scale applied).

## Checks beyond acceptance (tests/test_snapshots_extra.py)
- Non-symmetric factor L' = L Q (Q orthogonal) and wide factor L' = L Q (Q: d_X x 2 d_X with
  orthonormal rows): exact output DIS still equals H_Y (depends only on C_X = L' L'^T), and input
  DIS equals E[L'^T DF^T DF L'], confirming the L^T side. With the symmetric toy L this
  distinction is invisible to the acceptance tests.
- Exactly N `solve` calls and N batched JVP/VJP calls per builder.
