# T7: RBNO data assembly (`src/dis_tt/rbno.py`)

## Plan
1. Per sample: one `model.solve`; `xi = in_basis.encode(x)`; `eta = U^T (y - y_bar)`.
2. JVP branch (auto when r_X <= r_Y): one batched `jvp(state, L W)` with `L W = in_basis.V()`, then `U^T`.
   VJP branch: one batched `vjp(state, U)`, then `W^T prior.apply_sqrt_T(.)` (L^T, not L), transposed.
3. `sobolev_loss`: paper eq. for empirical risk (mathematical_setup.tex, Sec. 2.4 "Sobolev training"):
   mean_k [ ||eta_k - eta_pred_k||^2 / a0_k + ||J_k - J_pred_k||_F^2 / a1_k ];
   per_sample a0_k = ||eta_k||^2 + tau, a1_k = ||J_k||_F^2 + tau; global a0 = sum_k ||eta_k||^2 (+tau);
   none a = 1.
4. Extras: non-symmetric factor (L^T branch), r_X > r_Y auto branch, normalisations, validation.

## Source check
Paper TeX (arXiv:2504.08730v1 source, `sections/mathematical_setup.tex` Sec. "Sobolev training of
reduced basis neural operators"; `numerical_results.tex` Sec. "Neural network architecture and training"):
the experiments use per-sample a_{0,k} = ||U^T(F(x_k)-b)||^2, a_{1,k} = ||U^T D F(x_k) V||_F^2 (+tau optional);
the "uniform" alternative is a = sum_k of the same norms. Implemented exactly (`normalise="per_sample" | "global"`).

## Design choices
- One `solve` per sample and ONE batched jvp (block L W, r_X columns) or vjp (block U, r_Y columns) call;
  `meta["lin_solves_per_sample"] = min(r_X, r_Y)` under `branch="auto"`.
- VJP branch: J^T = W^T L^T DF^T U via `prior.apply_sqrt_T` (verified with a non-symmetric factor, 1e-10).
- `sobolev_loss` raises if any weight is zero (pass tau > 0); `"none"` uses unit weights.
- Helper `_sobolev_weights` is reused by T8 training.
